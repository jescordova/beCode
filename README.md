# Formation AI & Data Science — BeCode (coaching personnalisé)

Bienvenue ! Ce dossier est ta **salle de classe** pour te préparer au bootcamp
*Artificial Intelligence & Data Science* de BeCode. On va avancer **module par module**,
des bases jusqu'aux sujets avancés (ML, Deep Learning, GenAI, Data Engineering).

- **Langue** : explications en français, vocabulaire et code en anglais.
- **Format** : fichiers Markdown avec théorie, exemples, exercices et solutions.
- **Rythme** : on termine et pratique un module avant de passer au suivant.

> **Règle d'or** : on n'apprend pas l'IA en lisant, on l'apprend en **codant**. Chaque
> module contient des exercices. Fais-les avant de regarder la solution.

---

## Comment utiliser ce dossier

1. Ouvre le module dans VS Code (`code .` depuis ce dossier).
2. Lis la théorie, puis tape **chaque exemple toi-même** dans un fichier `.py` ou le terminal.
3. Fais les **exercices** sans regarder les solutions.
4. Note tes blocages : on les reprend ensemble au module suivant.

Le fichier [PROGRESS.md](./PROGRESS.md) sert à suivre ta progression.
